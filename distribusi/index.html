📲 Cara Install DIS-NRW
Pilih platform perangkat Anda
✅ Cara Otomatis (Chrome / Edge Android)
1️⃣ Buka DIS-NRW di browser Chrome/Edge
2️⃣ Banner "Pasang Aplikasi" akan muncul di bawah
3️⃣ Ketuk tombol ⬇ Install
4️⃣ Konfirmasi → aplikasi terpasang! 🎉
⚙️ Cara Manual (jika banner tidak muncul)
1️⃣ Ketuk menu ⋮ (titik tiga) kanan atas browser
2️⃣ Pilih "Tambahkan ke layar Utama"
3️⃣ Ketuk Tambahkan → Selesai! ✅
🍎 Safari iPhone / iPad
1️⃣ Buka DIS-NRW di Safari (bukan Chrome)
2️⃣ Ketuk ikon ⬆ Bagikan (kotak dengan panah ke atas)
3️⃣ Gulir ke bawah → pilih "Tambahkan ke Layar Utama"
4️⃣ Ketuk Tambahkan → Selesai! ✅
⚠️ Penting: Gunakan browser Safari untuk install PWA di iPhone/iPad. Chrome iOS tidak mendukung fitur ini.
✅ Chrome / Edge di Windows/Mac
1️⃣ Buka DIS-NRW di Chrome atau Edge
2️⃣ Klik ikon ⊕ Install DIS-NRW di URL bar kanan
3️⃣ Atau klik menu ⋮ → "Instal DIS-NRW"
4️⃣ Klik Instal → App terbuka di jendela sendiri! 🎉
💡 Keuntungan Install di Desktop
✅ Buka dari Start Menu / Taskbar / Desktop
✅ Tampil di jendela penuh tanpa tab browser
✅ Tetap bisa digunakan saat offline
✅ Update otomatis saat ada versi baru

ℹ️ Tentang DIS-NRW

DIS-NRW adalah aplikasi dokumentasi kinerja lapangan untuk Divisi Distribusi Air & Pengendalian NRW (Non-Revenue Water) PDAM. Dilengkapi GPS watermark otomatis, pratinjau peta satelit (Google Hybrid), panduan suara, dan ekspor laporan PDF format A4 presisi.
